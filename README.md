# BMW-sales report: 2015-'24
An Interesting sales visualization made using Power-BI.
Tech-stack:
Power-BI Desktop - Main data visualization platform used for report creation.
Power Query - Data transformation and cleaning layer for reshaping and preparing the data.
DAX - Used for calculated measures, dynamic visuals , and conditional logic.
Data Source : Kaggle.com
Features:
Goal of the dashboard - measuring total sales & revenue of BMW in a decade from different countries.
Key Visuals-
Donut Chart-- For a clean & concise overview of the whole report.
Time Series Graph -- Understanding BMW sales over a decade.
Conditional Bar Graph -- Top 5 countries the organization should focus more for constant revenue.
Map -- Which countries need better marketing for generating more revenue.
Business Impact - Helps in understanding what is the next best step for better sales.
